# Origin

TallyNet was bootstrapped from research code and docs in the sibling repository:

- Path (local): `../binary-optimizers`
- Especially: unary link experiments `experiments/v0_8_unary_link` … `v0_12_*`
- Naming discussion: `docs/TALLYNET_NAMING.md` (copied and adapted here)

**What moved:** tally-style multi-bit linear layers, encoders, small MLP, optional writeback training, unit tests, architecture naming.

**What stayed in the parent repo:** place-value / register Swarm ladders, optimizer zoo (voting, STE, …), DuckDB experiment store, large checkpoints/results, full WP roadmap.

The two projects may diverge; this file is historical context only.
